# Python Automation Tools
Production-ready, lightweight Python utility scripts designed for fast data cleaning, bulk file management, and routine task automation.

## Available Modules
1. **Text Sanitizer (`text_sanitizer.py`)**: Automatically cleans, normalizes, and strips messy whitespaces, tabs, and line breaks from raw text streams.
2. **File Organizer (`file_organizer.py`)**: Instantly scans messy directories and sorts files into categorized subfolders (Images, Documents, Scripts) by extension.
3. **CSV Data Cleaner (`csv_cleaner.py`)**: Handles messy datasets by stripping duplicate rows, purging empty records, and exporting standardized CSV outputs using Pandas.
4. **Web Scraper (`web_scraper.py`)**: Lightweight extraction tool for scraping main headlines and content links from target web pages instantly.

## Quick Execution
All scripts are modular and optimized for rapid execution via Google Colab or local terminal environments
